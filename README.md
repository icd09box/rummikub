# 루미큐브 (Rummikub) — 웹 버전

브라우저에서 바로 하는 루미큐브. 2~4인. 세 가지 방식:
- **같은 기기**: 번갈아 플레이(핫시트), 자리마다 사람/CPU 선택
- **온라인 방 만들기 / 참가하기**: 각자 자기 기기에서 접속. PeerJS(WebRTC) P2P로 방장 브라우저가 게임 상태를 관리하고 참가자는 행동만 보낸다. 서버·계정 불필요(최초 연결 중개만 PeerJS 공개 서버).

조작은 클릭 선택 → 대상 클릭, 또는 드래그 앤 드롭(마우스·터치).
빌드 없이 정적 파일만 있어 GitHub Pages에 그대로 올라간다.

**플레이**: https://icd09box.github.io/rummikub/

## 실행
```bash
python3 -m http.server 8080   # 그 다음 http://localhost:8080
node --test test/*.test.js    # 규칙·게임 로직 테스트
```

## 구조
- `js/rules.js` — 세트 판정(그룹/런/조커), 턴 검증, 점수. 순수 함수.
- `js/cpu.js` — 단순 CPU(손패 세트 탐욕 선택 + 테이블 덧붙이기).
- `js/game.js` — 게임 상태(배분·턴·뽑기·종료·점수).
- `js/view.js` — 플레이어 1명 시점의 화면 상태(손패는 본인 것만).
- `js/host.js` — 방장 로직(자리·행동 검증·턴 제한·끊김 처리). 네트워크 독립.
- `js/net.js` — PeerJS 연결(방 코드 발급·접속·메시지).
- `js/app.js` — 화면(설정 / 기기 넘기기 / 게임 / 결과).
- `test/` — node:test.

## 온라인 규칙
- 방 코드 5자리. `?room=CODE` 링크로 참가 탭 자동 진입.
- 방장이 2~4명 모였을 때 시작. 빈자리는 CPU로 채울 수 있음.
- 턴 제한시간 없음/60초/120초(기본 없음). 초과 시 자동 뽑기.
- 끊긴 참가자의 차례는 3초 후 자동 뽑기. 같은 이름으로 재접속하면 자리 복구.
- 방장이 새로고침해도 진행 중인 판은 localStorage에 저장돼 "온라인 방 만들기" 탭의 **이어하기**로 같은 코드·같은 판을 되살림(2시간 유효). 방장이 "그만하기"를 누르면 종료.
- WebRTC는 STUN + 공개 TURN(Open Relay) 중계를 함께 써서 LTE/5G·사내망에서도 연결되게 함(`js/net.js` `ICE_SERVERS`).
- 판이 끝나면 방장이 **같은 사람들과 다음 판**을 시작할 수 있고 점수는 판마다 누적.
- 로비에 참가 링크 QR 표시(qrcodejs CDN).

## 플레이 보조
- **한 수 취소**(직전 이동만) · **처음대로**(이번 차례 전체).
- **바닥 정리**: 내 화면에서만 묶음을 연속 묶음(색→숫자) → 같은 숫자 묶음 순으로 정렬해 표시. 묶음 요소의 `data-idx`가 실제 인덱스.
- 도움말(?)에서 **색 기호 표시**(색약 보조)·**내 차례 소리·진동 알림**(온라인)·**문제 타일 짚기**(규칙에 안 맞는 묶음에서 빼면 맞아지는 타일을 빨갛게, `rules.offendingTiles`) 설정. 게임 중 탭을 닫으면 확인창.
- 모바일: **2줄**(내 타일 두 줄 보기), **타일 칸 내리기**(내 타일 칸을 접어 바닥 넓게, 접힌 칸 위로 끌어다 놓으면 복귀).
- 온라인 **이모지 반응**(👍😂🔥⏰😱🙏): 차례와 무관, 자리마다 1.5초 1회, 모두에게 2.6초 표시.
- **홈 화면 추가(PWA)**: `manifest.json` + `sw.js`(같은 출처 네트워크 우선·캐시 폴백, CDN은 제외). 셸 파일을 바꾸면 `sw.js`의 `VERSION`을 올릴 것.
